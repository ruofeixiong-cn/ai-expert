# AI 专家平台 · 产品规划文档（一期 / 二期 / 三期）

> **文档定位**：这是产品的**顶层规划文档**，回答"这个产品要去哪、分几步走、每一步干什么、为什么要这样分"。
> MVP 的具体实现细节（技术选型、数据表、接口、验收）请看另一份《AI专家平台-MVP产品文档.md》。
>
> 本文档核心是三个东西：**定位跃迁、五层能力演进、数据飞轮**——它们决定了产品的一期/二期/三期怎么切。

---

## 0. 总览（一页看懂）

| 阶段 | 主题 | 一句话目标 | 核心动作 |
|---|---|---|---|
| **一期（MVP）** | 跑通付费闭环 | 验证"粉丝愿意付费 + 博主愿意供给" | 图文导入 + AI 专家对话 + 付费 + 反馈 |
| **二期（增长）** | 转起数据飞轮 | 让专家"越用越准"，博主"越用越赚" | 分成 + 盲区 + 多平台 + 订阅 |
| **三期（规模化）** | 五层能力全升级 | 从"会背书的搜索器"变成"会思考的 AI 专家" | 决策框架 + 人格复刻 + CRM + 重安全 |

## 1. 产品愿景与定位跃迁

### 1.1 愿景

> **让每个知识型博主的"知识和经验"，变成一个 24 小时在线、能变现、越用越准的 AI 专家。**

### 1.2 定位跃迁：从"娱乐"到"商业工具"

这是贯穿三期的**总基调**：

| 维度 | 数字分身（娱乐） | AI 专家（商业工具） |
|---|---|---|
| 心智 | 好玩、酷 | 专业、赚钱、省时间 |
| 目标用户 | 大众尝鲜者 | 知识型博主 |
| 付费意愿 | 低 | 高 |
| 对标 | 数字人聊天玩具 | 专家咨询、知识付费 |

**决策准则**：每个功能上线前问一句——"这是让博主更好玩，还是让博主更赚钱？"前者砍，后者留。

### 1.3 首页价值主张（定调）

```
把你的知识和经验，变成一个 24 小时在线的 AI 专家。
```

戳中的两个痛点：**"没时间"（24 小时在线）+ "想赚钱"（产生收入）**。

---

## 2. 商业模式：谁买单（总决策）

| 模式 | 谁付费 | 采用 |
|---|---|---|
| A. 博主付费（SaaS 订阅） | 博主 | ❌ |
| **B. 粉丝付费（付费咨询）** | **粉丝按次/订阅付费** | ✅ 平台 + 博主分成 |
| C. 混合 | 博主 + 粉丝 | 后期可演进 |

**决定影响**：
- 一期：博主免费建专家；粉丝付费提问（最简支付）
- 二期：加"分成体系"（平台→博主，博主持续供给的核心激励）
- 三期：可演进到"混合模式"（博主基础订阅 + 粉丝付费分成）

---

## 3. 五层能力演进路线（贯穿三期的技术主线）

这是产品从"检索"到"认知"的核心演进：

| 层级 | 回答什么 | 例子（理财博主） | 实现手段 | 落地阶段 |
|---|---|---|---|---|
| 1. 知识 | 是什么 | "定投手续费多少" | RAG 向量检索 | **一期** |
| 2. 观点 | 我怎么看 | "博主怎么看美股高位" | 观点库 + 立场标注 | **二期** |
| 3. 方法论 | 怎么做 | "博主选基金的 5 步" | 结构化流程模板 | **三期** |
| 4. 决策框架 | 该怎么选 | "我 30 岁该不该买房" | 决策树/判断规则 | **三期** |
| 5. 人格 | 像不像本人 | 语气、价值观、口头禅 | 系统提示词 + 风格样本 | **一期打底，三期深化** |

**核心洞察**：
- 第 1 层是"检索"，第 2~5 层是"认知"。
- **五层升级拼的不是模型，是"数据的结构化深度"**——观点、方法论、决策框架、人格都是从博主内容里"提炼"出来的结构化数据，不是凭空生成。
- **因此从一期开始，内容入库就必须打"类型标签"**（这是事实/这是观点/这是方法论），否则升级五层时全量返工。

## 4. 一期（MVP）：跑通付费闭环

### 4.1 目标

> **验证两件事：粉丝愿意为 AI 专家付钱；博主愿意持续供给内容。**

### 4.2 范围（8 项必做）

| # | 功能 | 说明 |
|---|---|---|
| ① 自动导入内容 | **图文优先**（公众号/知乎/微博/小红书文字） |
| ② 自动生成专家模型 | AI 生成七维 + 博主确认 |
| ③ RAG | 结构化四路 + 双闸门 |
| ④ AI 专家对话 | 流式输出 + 付费墙 |
| ⑤ 博主免费额度 | 免费建专家 |
| ⑥ 粉丝一键支付 | 付费提问（最简） |
| ⑦ Creator 最小看板 | 回答数/满意度/收入/盲区 |
| ⑧ 用户反馈 | 点赞/点踩（飞轮起点） |

### 4.3 成功指标

| 指标 | 定义 |
|---|---|
| 博主注册→上线转化率 | 注册博主中完成"专家上线"的比例 |
| 付费转化率 | 试聊粉丝中付费的比例 |
| 平均满意度 | 回答的点赞率 |
| 盲区率 | 被标记"疑似盲区"的问题占比 |

### 4.4 一期明确不做

视频/音频转文字、完整后台、CRM、分成、多平台、模型微调、数字人形象、本地向量化、重武器安全。

## 5. 二期（增长）：转起数据飞轮

### 5.1 目标

> **让专家"越用越准"，博主"越用越赚"——把数据飞轮转起来。**

### 5.2 范围（按优先级）

| 优先级 | 功能 | 说明 |
|---|---|---|
| **P0** | ① 分成体系 | 博主持续供给的核心激励，**二期第一优先** |
| P1 | ② 自动发现知识盲区 | 复用检索置信度，自动聚类负反馈 |
| P1 | ③ 自动生成补充内容建议 | 盲区 → 生成"建议博主补什么" |
| P2 | ④ 多平台内容同步 | 从单平台扩展到多平台 |
| P2 | ⑤ 视频/音频转文字 | 接入 ASR + 平台字幕，覆盖视频博主 |
| P2 | ⑥ 订阅体系 | 从"按次付费"升级到"订阅" |
| P2 | ⑦ 完整数据后台 | 从"最小看板"升级到完整仪表盘 |
| P2 | ⑧ 观点层（五层之 2） | 建"观点库"，博主立场单独维护 |

### 5.3 关键机制：数据飞轮的三个断点补丁

飞轮链路：
```
博主内容 → 知识模型 → AI 专家 → 用户提问 → 回答
  → 用户反馈 → 发现盲区 → 博主补充 → 更准 → 更满意 → 更多付费 → 更多反馈
```

**三个断点 + 补丁**：

| 断点 | 问题 | 补丁 |
|---|---|---|
| 用户反馈 | 用户没动机主动反馈 | 隐性反馈（点踩/追问/停留）+ 低摩擦点赞 |
| 发现盲区 | 反馈有了没人分析 | 复用置信度，负反馈自动标记"疑似盲区" + 盲区报告 |
| 博主补充 | 博主没动力持续补 | 金钱（分成）+ 成就感（仪表盘）+ 低门槛（补充=回评论体验） |

**最该盯的两个数**：**盲区关闭率**（博主补了多少盲区）+ **二次满意度**（补充后用户是否更满意）——决定飞轮是"真转"还是"空转"。

### 5.4 成功指标

| 指标 | 定义 |
|---|---|
| 盲区关闭率 | 博主补充的盲区 / 总盲区 |
| 二次满意度 | 补充后的回答满意度 |
| 博主月均分成 | 博主的持续收入（供给激励） |
| 复购率 | 粉丝二次付费比例 |

## 6. 三期（规模化）：五层能力全升级

### 6.1 目标

> **从"会背书的搜索器"变成"会思考的 AI 专家"，并支撑规模化多租户。**

### 6.2 范围

| 功能 | 说明 |
|---|---|
| ③ 方法论层（五层之 3） | 把博主"怎么做"结构化 |
| ④ 决策框架层（五层之 4） | 博主"怎么选"的判断规则 |
| ⑤ 人格层深化（五层之 5） | 风格样本 + 系统提示词复刻 |
| 粉丝 CRM | 粉丝关系管理（另一条产品线） |
| 重武器安全 | 内容审核、沙箱隔离、访问审计（配合开放分享/API） |
| 多租户规模化 | 每租户独立 schema / 库，按需升级隔离强度 |
| 混合商业模式 | 博主基础订阅 + 粉丝付费分成 |
| 本地向量化 | "原文零上云"的进阶隐私方案 |

### 6.3 关键机制：人在回路（Human-in-the-loop）

三期本质是 **"AI 专家 + 博主人为补充"的混合系统**——博主不是一次性提供内容，而是持续在回路里。

- 人格复刻、观点、决策框架这些"难自动"的部分，都靠飞轮的"博主补充"环节持续人工补上。
- 飞轮本身就是专家模型七维的**内容供给管道**。

## 7. 关键技术决策记录（ADR，防走回头路）

| # | 决策 | 结论 | 依据 |
|---|---|---|---|
| 1 | 定位 | AI 专家（商业工具），不是数字分身（娱乐） | 商业价值 > 娱乐属性 |
| 2 | 目标用户 | 知识型博主，图文优先 | 与"AI 专家"心智最匹配，入库成本最低 |
| 3 | 谁买单 | 粉丝付费（B 模式）+ 博主分成 | 呼应"产生收入"定位 |
| 4 | 内容形态 | 一期只做图文，视频转文字放二期 | 降低冷启动与实现成本 |
| 5 | 隔离 | 一期就做 tenant-level（RLS），不用 persona_id 过滤 | 隔离必须"基础设施强制"，不靠"应用层自觉" |
| 6 | 人格 | 不塞 System Prompt，结构化七维 + 常驻/检索分离 | 防 prompt 膨胀 + 上下文污染 |
| 7 | 专家模型 | AI 自动生成 + 博主确认 | 把供给任务从"写"降级成"改" |
| 8 | 安全 | 一期做轻量防御 4 条，重武器等开放分享/API | 攻击面在"内容"，不在"用户态度" |
| 9 | 数据飞轮 | 二期转起飞轮，盯"盲区关闭率 + 二次满意度" | 飞轮真转 vs 空转的分水岭 |
| 10 | 五层演进 | 知识(一期)→观点(二期)→方法论/决策/人格(三期) | 拼数据结构化深度，不拼模型 |

## 8. 风险与待决事项

### 8.1 关键风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 博主持续供给意愿不足 | 飞轮断掉 | 二期分成体系 + 成就感仪表盘 |
| AI 过度推断博主立场 | 信任崩塌 | 专家模型确认环节"防脑补" + Boundaries 硬约束 |
| 跨租户数据泄露 | 严重事故 | 一期就上 RLS + 来源标记 |
| 模型供应商数据政策变化 | 合规风险 | 选型时锁定"不用数据训练"承诺 |
| 粉丝付费意愿不足 | 商业模式不成立 | MVP 只验证这一件事，快速试错 |

### 8.2 待决事项

1. **首发平台**：图文内容先从哪个平台切入（公众号 / 知乎 / 小红书）？
2. **定价策略**：按次付费 vs 订阅 vs 混合，一期先测哪个？
3. **分成比例**：平台与博主的抽成比例（二期前需定）。
4. **粉丝端入口**：首页定位是给博主看的，粉丝从哪里进入产品？

## 9. 阶段复盘检查点（每个阶段结束问自己）

### 一期结束检查
- [ ] 粉丝真的愿意付钱吗？（付费转化率）
- [ ] 博主愿意持续供给吗？（供给留存）
- [ ] 专家的回答"像不像"？（满意度）

### 二期结束检查
- [ ] 飞轮转起来了吗？（盲区关闭率 + 二次满意度）
- [ ] 博主分成有没有形成激励闭环？
- [ ] 多平台 + 视频内容覆盖了吗？

### 三期结束检查
- [ ] 专家是"会思考"还是"只会背书"？（五层是否全落地）
- [ ] 规模化多租户稳不稳？（隔离 + 成本 + 合规）
- [ ] CRM 与重安全是否支撑开放分享/API？
